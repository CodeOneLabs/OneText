# Phone board, and the same harness on the desktop

Raw lines from the device harness (a throwaway project, not in the repository),
2026-11-24. Each cell is `median / p99 / max us`, then the share of the last
frame's characters drawn and, in brackets, the same share sampled every 50
frames. Arms: `OFF` every hot-path switch off (the code 0.4.2 ran), `ON` every
switch on, `DEF` the package's defaults (the official arm; the same as `ON` on
this build), `TMPdyn`, `TMPstatic`, and `TMPstaticNW` (TMP static with its
missing-character warnings disabled). Arm order is rotated per repetition.

Fonts for both systems: NotoSans.ttf, NotoSansArabic.ttf,
NotoSansCJKkr-Regular.otf.
