install

Just two steps. No baking.

Add the package. Put a label on a canvas. Type in any language on Earth: no atlas to bake, no charset to declare, nothing to configure first.

1 · add the package
// Packages/manifest.json
{
  "dependencies": {
    "com.onetext.core": "https://github.com/CodeOneLabs/OneText.git"
  }
}
2 · put a label on a canvas
// or: Add Component > OneText > Label
var label = go.AddComponent<OneTextLabel>();
label.SetFont(File.ReadAllBytes(path));
label.FontSize = 38;
label.Text = "สวัสดีชาวโลก";
fallback fonts, in one call
label.SetFont(latin, arabic, thai, emoji);
label.Language = "ja";   // locl: Han unification
label.CjkLatinSpacing = true;
label.PunctuationCompression = true;
typewriter, without a coroutine
label.CharactersPerSecond = 28;
label.RevealGranularity = Syllable;
label.SkipToEnd();      // the mash-to-skip button
label.RestartReveal();
Everything after those two steps lives in one window, the Hub (Window > OneText > Hub). First steps that tick themselves off, and every number a link to the screen that owns it.
Thai, Lao, Khmer and Burmese word lists ship inside the package, and one click installs them and re-measures word-break coverage against your own strings, not somebody else's corpus.
The string gallery, rendered headlessly by the package itself: every localised string in the box it has to live in, overflow framed in red. The pass this replaces is opening every screen in every language, by hand.
Doctor, the renderability lint: a character no font in the chain can draw, a locale whose line breaking needs a dictionary nobody installed. All of it decidable before the build, and it exits 1, so CI can fail the merge.

It is all included.
Except the paywall.

in the box

Everything in the box.

One package. Every feature. Nothing sold separately. Somewhere else, this list is a price sheet.

  • Shaping & bidi HarfBuzz GSUB/GPOS and the full UAX #9 algorithm. Arabic, Devanagari, Thai, Khmer, Myanmar, Tibetan: contextual forms, reordering, mark stacking
  • Rich text & emoji Named styles you edit once and every label follows, inline sprites, colour emoji including ZWJ sequences, flags and skin tones
  • Text animation Typewriter by grapheme, orthographic cluster or syllable, per-punctuation pauses for CJK and Thai, <wait=>, skip, per-unit callback, per-cluster effects and a custom-effect API
  • Asian typography Kinsoku, punctuation compression, CJK-Latin spacing, Korean word wrap, dictionary line breaking for Thai, Lao, Khmer and Burmese, and a josa tag
  • Outline, shadow, glow Packed into vertex channels already paid for, so a decorated label and a plain one still share one material and one draw call
  • An input field that survives an IME Inline composition drawn at the caret with a Japanese clause highlight, no syllable lost or doubled on focus change. Input Manager, Input System and the mobile soft keyboard
  • The Hub Fonts, charsets, dictionary import with before/after coverage, atlas occupancy and budget advice, a string gallery that flags overflow per locale, and Doctor, a renderability lint that exits 1 so CI can fail a merge
Outline, shadow, glow: every row is one material, one canvas, one draw call. The Arabic line is the one that matters: the outline follows the joined contour, where a per-glyph outline shows a seam at every join.
Vertical writing (縦書き): columns right to left, the same line-breaking and kinsoku pipeline turned ninety degrees, Latin rotated by UAX #50, ruby beside its column. No Unity text solution, first-party or paid, has this.
Ruby (furigana) placed by the published rules: slack distributed under a narrow reading, a wide reading allowed to hang only over a neighbour's blank, base and reading unbreakable across a wrap. Compare the padded row with the overhang row: the punctuation gave up its blank, and the line stayed tight.
The per-label precise option: multi-channel distance fields keep corners sharp at display sizes, where a single channel rounds them off. Same material, same draw call: a precise heading still batches with the paragraph under it.
